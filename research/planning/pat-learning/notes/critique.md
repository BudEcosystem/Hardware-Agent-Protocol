# Reuse is not yet inference-free routing

The evidence supports reusable executable skills inside an LLM-driven planning system. It does not establish HMS's requested contract: recognize an admitted situation, bind parameters, and run a deterministic Program as Tools (PAT) without another model or embedding call.

## Paper evidence and limits

[Voyager v2](https://arxiv.org/pdf/2305.16291v2), §2 and Appendix A, combines curriculum generation, embedded skill descriptions, code synthesis, and model-based critique. Appendix B.4.4 reports 96.5% top-five retrieval accuracy over 309 samples; retrieval supplies synthesis context, not a certified executable choice. Experiments measure prompting iterations with three trials, not inference-free operation or physical timing. Transfer clears inventory and uses new worlds while retaining model calls.

Two appendix examples qualify the reuse claim. `craftWoodenPlanks` computes a log choice before acquiring missing logs and never refreshes it; the initially empty case can therefore pass an invalid plank name. `catchFiveFishSafely` contains an unbounded water-search loop and cancellation retries despite Prompt 4's prohibition on infinite loops. These are static source observations, visually checked on pages 30, 32, and 34, not reproduced executions. A successful trajectory cannot establish all future preconditions or bounded termination.

The paper acknowledges incorrect critics and hallucinated tasks. Minecraft recovery assumptions differ materially from physical actuation. No hardware reliability claim follows.

## HMS design deductions, not established Voyager results

A generic Arduino endpoint can run admitted parameterized procedures through a fixed capability interface; it need not receive a new application sketch for every task. The natural-language agent should propose a typed intent and select a compatible capability/procedure contract. A language description is useful for discovery and explanation, but should not confer execution authority.

For strict zero-inference reuse, define the scope precisely. A known structured request or recognized grammar can select a program through checked predicates. Arbitrary new natural language may require interpretation and therefore belongs on the novel path. Cached generated text, an embedding query, and an LLM router are all different from deterministic predicate evaluation. Local inference is still inference. Count selection, parameter binding, success checks, and recovery—not merely time spent inside the executor—when measuring the claim.

Experience should create a candidate with immutable source/IR and dependency hashes, typed parameters and units, resource/effect bounds, contextual preconditions, expected outcomes, provenance, and negative cases. Promotion should require an explicit validation receipt and an atomic registry revision. A later replacement must not silently change an already-admitted caller. Observed success contributes evidence; it does not itself promote authority or widen the applicability domain.

The deterministic selector needs a documented priority/uniqueness rule and an abstain result. Match device/capability revisions, sensor validity and freshness, calibration/frame identities, clock and authority epochs, allowed resources, and parameter ranges. Unknown, stale, ambiguous, mismatched, or failed contexts must stop that automatic route. Novel planning may propose a new candidate; it must still pass the same admission boundary.

Execution must independently enforce bounds, resource ownership, deadlines, cancellation, failure outcomes, and replay/operation identity. Endpoint acceptance is not physical completion. A previously valid sample is not a perpetual authorization grant. Reports should distinguish proposal, admission, start, completion, cancellation confirmation, and uncertain outcome. Experience records must retain unsuccessful and ambiguous attempts to prevent success-only selection bias.

No such HMS runtime or promotion engine is implemented by this research lane. The parent design owns the normative PAT specification; these observations supply evidence and adversarial examples.
