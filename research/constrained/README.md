# Constrained protocol and serial research

This lane contains supplementary acquisitions for the original protocol corpus and the experimental serial binding. It is reference material, not a statement of supported devices or certified protocols.

- [CoAP acquisition manifest](coap/manifest.jsonl), [full-reading receipt](../protocols/reading-coap-full.json), [critical review](../protocols/notes/coap-full-review.md) and [binding proposal](../../docs/coap-binding.md): RFC 7252 plus fully read RFC 9175, RFC 8974, RFC 9876 and four errata indexes. A duplicate status rendition is only partially inspected. Blockwise, Observe, OSCORE and concrete transport security remain separate gates.
- [Historical LwM2M Core review](../../docs/lwm2m-binding.md) retains the complete 2020 Core 1.2 reading and its source limitations. The [current Core/Transport 1.2.2 review](../../docs/lwm2m-current-binding.md), [reading receipt](reading-lwm2m-current-full.json) and [acquisitions](lwm2m-current/manifest.jsonl) supersede its selected-only current-version status: both available published HTML texts and all 48 semantic figures are now read. Missing normative Appendix K content, separately acquired XSDs, publication conflicts and three unread PDF text renditions remain explicit.
- [Serial acquisition manifest](serial/manifest.jsonl), [full-reading receipt](reading-serial-full.json) and [source critique](serial/notes/framing-review.md): RFC 1662, its errata and the currently archived UNO R3 manual fully read. Direct acquisition of the Arduino comparison page failed 403 and is retained as a gap.
- [Complete EDHOC review](edhoc-full/README.md) and [binding analysis](../../docs/edhoc-binding.md): full RFC 9528 text, all thirteen ASCII figures and fifteen tables; selected PDF corroboration remains separate. Authentication/key establishment does not replace HMS authority, replay or uncertain-effect records.
- [Complete Q-Block review](qblock-full/README.md), [reading receipt](qblock-full/reading.json) and [binding proposal](../../docs/qblock-binding.md): full RFC 9177 text, all twenty figures and five tables, both appendices, current metadata/errata and relevant IANA allocations. Visual corroboration covers 21 of 41 PDF pages; the broad registry HTML remains selected-only. The earlier introductory Q-Block coverage is preserved. Exact size/body recovery does not establish atomic procedure execution, contiguous sensor history or physical cancellation; the proposal requires inert staging, immutable object/operation identity and bounded assembly/recovery.
- [Embedded code review](../embedded/README.md): complements the standards with exact parser, scheduler, motion and executor source inspection.
- [AVR acquisition manifest](avr/manifest.jsonl), [core-source receipt](reading-avr-full.json) and [target build/UART review](avr/notes/target-build-and-uart-review.md): pinned official toolchain/core archives; fifteen full core files and selected board definitions; original parser cross-linked for ATmega328P without execution or flashing.

Later receipts state exact reading coverage without converting source acquisition into an inferred read. All raw files retain their source copyrights/licenses. The independent [serial implementation](../../protocol/serial/README.md) tests only an original framing layer; no research checkout was executed, and no UART, MCU firmware or physical device was exercised.
