## Behavioral controls for the proposed refactor

1. **Complete time domain and ordering.** Use independent literal expected values and the old unsigned64 expressions as a reference, not the new helper implementation. Cover 0, 1, every byte carry/borrow boundary, `0x7fffffffffffffff`, `0x8000000000000000`, `UINT64_MAX-1`, and `UINT64_MAX`; strict before/equal/after comparisons; unsigned subtraction with and without a preceding order check; zero/1/60000/UINT32_MAX bounds; exact saturation thresholds and min ties. ABSENT is tested both as a bit pattern in the arithmetic leaf and under each caller's distinct sentinel policy. No test assumes upper32 bits are zero.
2. **Finite captured-time semantics.** Admit a request whose nb/latest/complete/lease contain nonzero high bytes and different boundaries. Advance the fixture clock at `describe`, guard and clock-sample boundaries. Verify the same first failure/status, no ownership/fence change on rejection, and use of the original captured request times after callbacks. Keep the callback immutability contract; injection changes only modeled external clock/authority inputs, never illegally mutates executor storage. Full before/equal/after latest/lease cases must traverse the real public handler, not only a numeric helper.
3. **Standing callback traces.** Retain acquisition-at-cutoff refusal, epoch/USART/clock drift after the initial loop check, exactly one actual I/O handoff per activation identity, and before/equal/after dispatch/witness tests. Assert callback order/count, report/effect identity, shared held resources and the complete response bytes. Removing a redundant arithmetic evaluation must not remove a required guard, clock read or actual-boundary check.
4. **Observation commit separation.** Both channels: accepted new sequence copies the same 24 bytes and adds only its own ready flag; equal-sequence/equal-content is a no-op; equal-sequence/different timestamp/value/epoch refuses without partial commit; stale/quality/gap/range failures keep their old reason and loss behavior. Verify both demand and feedback records after the real poll, including the retained full-range direction/improvement case.
5. **Loss/ACK/resume.** Suspend with feedback pending; a loss report with unknown handoff cannot establish quiescence or permit ACK; acquisition at the handoff tick is refused, strictly later valid aggregate evidence settles only the existing rules. The public quiescence time remains ABSENT while the private alias holds a handoff time. Interrupted feedback remains possible-effect/unverified and cannot be discarded before valid aggregate settlement. Resumed PREPARED keeps continuity/claims and source watermark; STOP/RETIRE preserve all old release gates.
6. **Serializers and alias/lifetime review.** Compare exact HELLO, control, receipt and both DESCRIBE pages, plus standing status pages/error responses and null output/length behavior. Native timestamps use high bytes and byte carries; identity, context, fence floors and response sequence remain exact. Capture field read/write order in the review and preserve each old scalar snapshot before writes. The test fixture must not grant a new overlap guarantee or hide a changed lifetime by copying everything up front.
7. **Common authority and error priority.** Finite operation while standing occupies the tagged slot and every v1 query/control/retire path retain the existing refusal. Conversely a finite owner prevents standing OPEN. Include requests with several invalid fields so syntax, boot/context, revision, lease, guard and resource errors still appear in their original precedence; invalid requests must have the same callback trace and no partial claim.

A useful integration oracle is a fixed corpus of complete event traces run against the exact frozen baseline and candidate in separate binaries under the same reviewed runner. Compare serialized replies, retained controller/endpoint logical bytes, callback trace, I/O effect identities and ledger transitions after each step. Explicitly normalize addresses only, never state/counters/timestamps. Keep independently specified boundary cases so agreement does not merely preserve a common bug. This differential harness is proposed work, not present or executed here.
