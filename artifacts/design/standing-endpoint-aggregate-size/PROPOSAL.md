Implement the catalogue in one new isolated successor, with exact current parent sources and controls as its independent baseline. Do not modify this design's parent or the public project. The first executable candidate must include the coordinated finite/standing validation and ordered codec integration, not just one helper.

1. Add private field-plan implementation files beside endpoint_kernel. Keep the existing numeric backend, public headers, driver signatures and retained serializer entry points. A compiled plan may call only pure field readers/comparators or ordered field writes. It cannot call a driver, clock, guard, constant callback, source_epoch, loss/revision routine or claim operation.
2. Replace the catalogue's contiguous pure predicates at their exact old statement points. C still selects the phase and handles its returned original status. There is no plan branch instruction: conditional subexpressions, lifecycle switches, counter changes and callback-separated phases remain C. No plan result survives a callback.
3. Replace the five ordered codec groups with descriptor walks. Preserve existing helper signatures as wrappers so required alias/entry surfaces are not removed. Keep constant-byte and source-epoch callbacks in their existing C positions. Keep response length stores and reads in C at their old positions.
4. Retain the finite handler/poll boundaries and current standing service boundaries. Do not add blanket noinline to public runtime or driver roots. Sharing of the two private walkers may use the existing conditional GCC convention, with emitted-body/clone checks required later.

The rule encoding is an eight-byte byte array, independent of C struct padding: `operation, left-key[2], right-key[2], auxiliary-key[2], failure`. A key has a native-object-format bit, a three-bit base selector and a twelve-bit byte offset. Source plans use only the documented object ranges. Native offsets come from offsetof, with static range assertions; encoded offsets remain the existing wire offsets. Base7 is the private flash constant pool, base6 is unavailable, and bases0..5 are caller-owned read-only views established at the old capture point. No caller can supply a plan or row count through the protocol.

Required operations are unsigned relation at widths1/2/4/8; signed32 relation only; bounded nonzero bytes (the existing32-byte digest case); masked-zero byte; full64 modulo elapsed versus an unsigned32 bound; and the existing conditional future-horizon check. The latter first compares future with now and performs subtraction only when future>now. These correspond to actual catalogue expressions. Do not add general jumps, loops controlled by input values, arithmetic stores, arbitrary function pointers, mutable plan state or a generic expression language.

Rules stop at the first false required predicate and return its original failure byte. Evaluation uses lazy per-row reads. It must not eagerly decode a request or cache the entire endpoint. Only values already captured by the original source are supplied from captured views. Signed32 order can compare sign-biased most-significant bytes; time values remain unsigned full64. The scalar qualification fallback independently evaluates the same relations. Bounds and ABSENT policies remain explicit rows or C conditions; modulo subtraction is never replaced by a chronological assumption.

The codec row is also eight bytes: `operation, destination-offset, source-key[2], auxiliary-key[2], fixed-count, flags`. The five groups have one destination base and up to six source views. Supported operations are raw memcpy with the original defined-overlap precondition; native16/32/64 to big-endian with a complete per-field source snapshot; a literal byte; and a raw copy whose length is read from the exact original source field immediately before that copy. No descriptor performs a state decision or arithmetic. The largest native snapshot is8 bytes. Native16 writes high byte first; native32/64 preserve the old descending destination-index order. A descriptor group is split wherever the old code observes a callback, performs a decision, or changes a pointer used by a later group.

The 42-byte constant pool is zero8, FF8, INT32_MAX4, signed−1000004, 2000004, 3000004, 1000004, 60000u16, 1u16, 32u8 and 0xc1u8. The exact serialized values and offsets must be emitted as literal bytes. No native pointer table or plan directory is needed: wrappers name the plan symbol and compile-time count directly.

The opcode/length tables replace only trusted lookup metadata. They do not cache an opcode across update. Finite code recognizes p[1], updates, then captures/reloads as before. Standing code captures its dispatch opcode before refresh but its syntax routine reloads p[1] after refresh. The separate lookups and the finite CALL's special pre-length error order remain. No version, opcode, response/page or public wire layout changes.

On the fixed AVR profile, every descriptor and pool byte must be PROGMEM and accessed through the pinned avr-libc pgm_read_byte path. The retained header defines PROGMEM as a program-memory attribute and the near reader in terms of LPM; lower64KiB placement is a required generated-map check, automatically compatible with a *valid* original32KiB image but not assumed from source. Native builds use ordinary const data. Plain const on AVR is not an acceptable substitution because its SRAM copy would violate the unchanged static allowance. Charge all LPM instructions, access helpers, table alignment, interpreter dispatch and relocated literals in the final map.

The validation view array is at most six pointers:12 bytes on AVR. It is automatic, not retained, and must end before callbacks. A proposed streaming walker needs at most eight bytes of decoded row metadata, four bytes of bound and four bytes of loop/result bookkeeping; its source-level automatic object budget is16 bytes, in addition to the caller's views. It need not snapshot comparison operands because it neither writes nor calls out. The scalar fallback may have wider native temporaries and is not the AVR size implementation. The codec needs one8-byte per-field snapshot plus row/index/pointer state; use a24-byte source-level automatic budget before caller views. These are design ceilings for declared objects, not generated stack limits or permission to reduce the512-byte reserve. Charge caller-saved registers, outgoing arguments, return PCs, nested numeric helpers and ISR preemption separately.

Existing32-byte finite timestamp captures, standing acquired/time captures and the32-byte poll report remain. Do not add another report, persistent decoded state, response cache or heap. Actual compiled static storage must remain1,503 bytes or lower without dropping a charged root; the planned160-byte delta is already fully used.

Before any execution, root review must receive all literal rows, all call-site changes, an exact original-to-row map, the added controls, source pins and the bounded owned runner. The present catalogue is a source plan, not generated C or evidence of a successful build. Later measurements must include all newly added bytes and all unchanged services, and preserve a failed link unchanged if the full target still does not fit.
