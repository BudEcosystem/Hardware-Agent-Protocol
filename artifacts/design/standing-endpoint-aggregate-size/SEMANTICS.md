The replacement is permitted only where a complete contiguous group is pure or an explicit ordered copy group. It does not change which states authorize a callback or an effect. Every table has an exact original-source location and an explicit C caller; it is not a new protocol capability or remotely selected program.

For pure predicates, each row is read lazily and evaluation stops at its original first failed expression. No view preloads native field values. View pointer setup may name an existing captured object but may not introduce earlier dereferences of a configuration pointer or missing report field. Short-circuit conditions that decide whether another field is valid remain C boundaries. The evaluator cannot read beyond a previously validated field extent merely because a plan is trusted.

Endian conversion is private representation work. Use unsigned-character reads for known native layout in the explicitly selected byte backend, with the same compile-time representation guards as the parent. Full-width unsigned ordering is lexicographic most-significant byte ordering. Signed32 ordering flips the sign bit in the most-significant compared byte. Full elapsed comparisons propagate borrow across all eight bytes and discard only the final borrow, preserving modulo2^64. The future-horizon operation separately preserves its original order guard. It cannot replace separate loss chronological checks or reinterpret ABSENT as a smaller time.

The codec's per-scalar8-byte snapshot is necessary even if most installed output buffers are separate. Do not assume response is disjoint from endpoint fields when the old C has defined behavior. Keep explicit scalar write order: put16 high then low; put32/put64 descending indices after capturing the whole scalar. A raw memcpy row has exactly the old source, destination and length at that point; it does not broaden a test claim to previously undefined overlapping memcpy calls. The source and destination views for each codec group must match the pointers the old function actually captured. In particular, receipt's r pointer is captured before the first identity copy, and its result length is read separately for the byte, copy and returned length.

Output-alias checks must also cover the standing header before any codec is called: memset(out,0,66) precedes the original reload of request[1]. A rewrite must not use the earlier dispatch-op capture for that reload. Likewise, do not cache a current native object field across a write that can affect it. Pointer-bearing source regions stay in explicit C or separate groups until an exact lifetime/alias proof is supplied.

There is no reservation change. Tables and pool are immutable flash bytes, never extra SRAM state. The existing operation buffer, standing128-byte record,256-byte arena, attachment/config glue and stop/clock/NVM/UART reservations retain their full charge. A flash fit cannot establish stack fit; added view frames and access/dispatch calls must be included in the eventual foreground/ISR graph.
