# Bounded source and verification plan

1. Preserve the sealed shared-kernel parent and phase-size design. Verify parent index and every indexed file, then keep 40 exact original project files and source pins. All edits remain in this successor.
2. Keep immutable core-draft01 and controls-draft01/02/03 snapshots. Review the complete final core delta, the new digit/overlap/callback/loss controls, the exact runner delta and metadata before execution. Source review is not behavioral or generated-code qualification.
3. After root review, the native stage uses the trusted pinned host compiler through the unchanged owned runner. Run original finite/pipe tests, runtime controls, unchanged 14 standing controls, six numeric groups with each candidate backend, and 20 differential groups against parent/byte/fallback in plain and ASan/UBSan modes. Observe assertion/trace counts and require agreement; do not invent them in advance.
4. After native assessment, one explicit AVR stage may compile/link the same byte candidate using the retained reviewed GCC 7.3 toolchain and original ATmega328P profile. Preserve any warning, tool-query refusal, link overflow or other failure in its attempt. Never run the ELF, emulate, flash or open a physical device. A changed attempt needs a new explicit number; never overwrite a previous receipt/build.
5. Review the complete map and final generated functions, aliases, roots/storage, caller frames, byte loops and ISR graph. Static-plus-reserved-stack arithmetic is not combined stack proof. Preserve unsupported fit if the link fails or the unchanged application/storage bounds are exceeded.

Each outer command retains 60-second wall, 30-second per-process CPU, 64MiB file and 512MiB non-sanitized address limits, with observed process-group RSS capped at 512MiB. These are the inherited embedded bounds, not the separate host-provider 30-second profile. Cleanup retains anchored group settlement, dedicated subreaper/pidfd ownership and complete receipts; SIGKILL/host failure is not qualified. The owner helper is copied/pinned, not loaded during preparation.

The candidate adds no persistent state, reserve, table, VM, public ABI/root removal or reduced time domain. Native-only phase_access.c is excluded from AVR and other firmware links. Its direct accounting probe establishes a private phase behavior, not physical reachability or a new deployed API. Further source changes must be reviewed as exact deltas from the snapshots.
