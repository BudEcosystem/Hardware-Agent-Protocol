# Independent I/O procedure-history component

This isolated candidate keeps all 2,804 operation-history inputs unchanged and
adds a pure parent-sequence checker with 34 tests. The combined selection is
146 methods: 34 procedure, 38 operation, 35 board-history and 39 reader methods.
No tests or project imports occur during source preparation.

The checker first runs the independent operation fold, then derives parent state,
cursor, cancellation delivery, events and child links from the observed call
schedule. A cycle has a parent stage before adapters and another after adapters.
A child admitted after adapters must still be accepted, without a dispatch ticket.
Successful prefix advancement requires completed children with no held claims;
a provider receipt or parent status assertion alone cannot satisfy that rule.
Parent completion precedes deadline refusal when every child is already settled.
Active parents interrupt on reopen. Resume checks remaining child outcomes,
start/lease windows and original session identity; historical completed children
need no fresh session binding. Cancellation uses the child's pre-call state, so
accepted cancellation is delivered as recorded, not retrospectively terminal.

Every parent event and every mutable row field must equal the derived sequence.
Returned submit/resume/cancel statuses, drive return shape and all intermediate
and final observations must match independently derived child projections. Exact
parent replay emits no new admission or event. Parent row sequence is compared
with a bounded generated history, never used as a range-allocation request.
Adversaries first pass both structural and child-operation inspection. Actual
fixtures are expected to retain 18 parents and 105 parent events across 19 trials:
9 completed, 5 canceled, 1 failed, 1 running, 2 accepted, and one unsubmitted trial.
The missing current receipt continues to expose one unresolved operation/claim.

The supported profile is finite, single-parent, single-PAT-actor synthetic I/O.
No producer, ProcedureStore, Journal, runtime, provider validator or worker is
imported. Shared invocation hashing and independent transcript/operation helpers
are used. The captured compiled plan is not independently lowered from PAT input.
Missing admissions due to uncaptured policy/configuration failures, unsupported
submit/cancel failures and denied cancellation delivery are not silently accepted.
General failure-cause attestation, physical clocks, auxiliary actors, complete
configuration, PAT correspondence and matrix qualification remain unfinished.
Board-history inspection is separate. Qualification and full-outcome flags remain
false even for a coherently completed parent. This is evidence computation over
trusted-source retained data, not execution attestation or physical sensing.

No live runtime, earlier frozen input, adjacent Harness checkout, real device,
MCU, emulator, live inference or external service changes. Helper accounts remain
usage-limited; primary-agent source review is not an independent agent review.
