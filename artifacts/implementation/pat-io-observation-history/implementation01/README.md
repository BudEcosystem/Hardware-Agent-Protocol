# Independent finite-I/O observation history

This isolated candidate checks exactly when the finite trial executor samples
each installed input. Baseline and reopen create sequence-one streams sampled
from the current board. Each driven cycle, procedure or adapter phase takes one
fresh sample before any phase effect; other checkpoints retain the existing
sample. All properties and instances must follow this schedule. A new activation
can therefore leave a valid cached observation behind the current board counter.

The values represent synthetic activation counters and an installed-ready flag.
They are not measured electrical output, completed-cycle counts or physical task
success. The checker derives sample values from independently validated board
history, with trusted configuration, permissions, PAT correspondence and guarded
receipt causes. Recovery additionally requires the separately trusted fault plan.
No producer/runtime/provider implementation is imported.

`inspect_observation_history` checks this component for all 26 existing configured
trial fixtures, including two pre-effect permission refusals. It explicitly
leaves operation/parent history flags false. `inspect_observed_execution_history`
also invokes the existing full authority and parent composition. It preserves
both existing permission-refusal limitations; it never substitutes the sample
component when full execution validation fails. Those two extensions remain work
for the corresponding event/parent cause validators.

The new source consists of one module and 27 test methods. All 7,056 inherited
project/data files are copied unchanged; no new runtime execution or capture is
needed. Tests cover all twelve configuration, six active-withdrawal and eight
pending-recovery fixtures, full composition, rehashed sample lies, exact sampling
order, and purity/input immutability. Several adversaries first pass the previous
history checker to establish the missing semantic check. Inherited 136-test
results remain historical; this stage selects the 27 new methods only because
no inherited code or test was changed.

Preparation used only standard-library parsing and data inspection. The retained
fixtures contain 434 snapshots, 1,288 produced samples, 134 drive refreshes, 26
initial batches and one reopen batch. Seventy-two snapshots contain a legitimately
lagging value. These counts are preliminary data-only findings until the selected
checker tests execute. The independent sample checker is not a complete outcome
or qualification oracle; physical measurement, current compiler identity, full
timing/fault coverage, aggregate enforcement and public qualification stay false.

The original 4,096 combined records, 16 MiB evidence, 64 KiB documents and 2,048
tick bounds remain unchanged. The pure harness keeps its original 180-second
deadline and 16 MiB scratch ceiling. No physical device, MCU/emulator, live
inference, public service or acquired controller executes. No live HMS source or
adjacent Harness checkout changes. Review is by the primary agent; helper usage
limits prevent independent agent review. Results will be retained separately.
