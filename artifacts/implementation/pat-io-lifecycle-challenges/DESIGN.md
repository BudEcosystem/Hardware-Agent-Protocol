# Fixed cancellation, restart, reply-loss and retained-read challenges

This isolated stage executes the ten remaining lifecycle/permission definitions
from combined matrix 0.3 on both GPIO and PWM. It inherits all 8,098 project files
from the sealed authority semantic stage without changing runtime, providers,
compiler, policy, matrix, transcript grammar or existing tests.

The new worker validates the complete matrix before creating a private runtime.
It runs only these fixed cases: accepted/pending cancellation, accepted/pending
reopen, lost activation/completion replies, and invocation withdrawal before
parent admission, before dispatch, while pending and after board completion.
Permission changes retain explicit read access and never restore invocation.
Reopen preserves the compiled request and its original child keys. No suffix is
rebound to the new endpoint session. Fault injection occurs at an explicit
single boundary around the original implementation; the boundary and occurrence
are retained separately from raw execution/configuration tables.

The pure reader independently reconstructs each fixed artifact/case and its exact
call, clock, reopen and failure schedule, and checks original lowering against
the actual resolved environments. It checks the complete grant snapshots against
the separately supplied trusted change schedule. These are request/schedule
checks, not a complete independent semantic fold or qualification decision.
Targeted tests inspect actual retained effect counters, receipts, claims, parent
and child states, old requests, session changes and absent suffix work.

Four disjoint bounded test selections exercise five actual cases each; an extra
pre-runtime refusal method belongs only to the first selection. All retain the
original 180-second harness deadline, 16 MiB scratch, 8,192 input-file ceiling,
per-trial 60 seconds, 4,096 combined records, 16 MiB producer evidence and 64 KiB
manifest bound. Every original raw scratch tree and failed attempt is retained.
There is no group quota claim: actual current-candidate matrix execution,
complete independent expected-response composition, attestation and public PAT
qualification remain subsequent work. Physical devices, MCU execution, inference
and live services are outside these synthetic trials.

Primary-agent source/diff review is required before these original local tests.
Independent helper review is unavailable because the existing helper agents
report an account usage limit. No independent review is claimed.
