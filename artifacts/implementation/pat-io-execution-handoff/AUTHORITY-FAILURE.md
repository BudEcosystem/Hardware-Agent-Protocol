# Retained authority-challenge failure after owner loss

The [spawn-loss attempt](results/attempt27-failed-crash-spawned/failure-audit.json) retains one original worker and a canonical failed return. Its group completes 26 of 30 cases and stops in `full_authority_withdrawal` with `PAT_IO_AUTHORITY_UNEXPECTED_FAILURE`. Recovery archives the same attempt as `OWNER_LOST`; no second worker is launched. This is not recorded as `PAT_IO_GROUP_WALL_LIMIT` and must not be silently relabeled as a deadline failure.

The complete output closure contains 3,315 files and 12,168,664 bytes. The current case has 130 canonical trial records and no completed manifest. Its last recorded public call is `read:operation`, phase 12. The call fails with `ACCESS_DENIED`, followed by a retained `read:operation:after_error` checkpoint. No subsequent `call_started` record exists. The retained synthetic state has completed cancellation of this case's earlier activation; this does not establish full-matrix success. Across all 23 inspectable states there are 16 activations, seven completions, nine cancellations and no retained claims or board owners.

The [authority challenge's `_denied` helper](implementation01/project/hms/pat_io_authority_capture.py) catches `JournalError` around the entire instrumented call. If its code differs from the expected refusal, the helper emits only `PAT_IO_AUTHORITY_UNEXPECTED_FAILURE`. The [instrumented call](implementation01/project/hms/pat_io_trials.py) performs budget checks and before/after capture as well as the public operation. Consequently an instrumentation or budget exception can replace the expected operation error, or occur before the next operation is recorded, and then be masked by the refusal helper. The [group budget](implementation01/project/hms/pat_io_group_budget.py) also checks elapsed time at these boundaries.

This source path explains a possible masking mechanism; the retained group error does not include the caught inner code or a traceback establishing that mechanism in this particular run. The fixed simulated timestamps are not measurements of worker wall-clock time. The cause remains unproven. The trace does not demonstrate a public-access bypass: its final recorded public error is the expected denial.

The [independent reader](audit-failed-authority-return.py) verifies the original request, attempt, output closure, worker image, crash receipt and the final trace records without importing project code or altering state. A future fresh-source correction should preserve the original operation error and any capture/budget error separately, with bounded phase/context fields. It must not swallow the latter, declare the scenario complete or relax its original limits. The failed run remains immutable and is not relaunched for diagnosis.
