# Isolated trial20 harness

The launcher/child adapt the retained pure65 harness to twenty original IoRuntime
phase-engine methods, using the existing original-I/O timeout and raw retention
ceilings. Exact source/dependency acquisition, actual origins, bytecode refusal,
owned-child cleanup and original scratch retention are preserved. The added
SQLite gate ties each database connection to the current test's exact private
state; terminal retention checks every engine record and database association.

See [scope](SCOPE.md), [targets](targets.json) and [index](index.json). The released
command is:

```
python3 artifacts/implementation/pat-io-trial-engine/harness01/run_attempt.py attempt01-trial20 --parent-released
```

Preparation performs source/AST/hash checks only. Actual attempts retain their own
results, original state, copied state and logs. A green suite is evidence about
this original host model and its record capture, not physical execution or an
independent I/O qualification decision.
