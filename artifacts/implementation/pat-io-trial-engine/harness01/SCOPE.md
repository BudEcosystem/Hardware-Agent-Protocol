# Original trial20 execution scope

The closed selection contains 20 original tests of the new phase engine with the
actual copied IoRuntime, compiler, resolver, procedure manager and GPIO/PWM model.
There are 20 private test workspaces, 19 engine states and 38 distinct databases.
The nonempty-directory refusal case creates a marker only. A deliberate missing
receipt case remains unresolved; the suite must preserve that fact.

The child runs with `-I -S -B` and acquired project/selected dependency origins.
Network and subprocess creation remain forbidden. SQLite is allowed only in the
current selected test's exact `trial-0/state` directory, for authority.db or the
synthetic shared-board database. This cooperative audit is not an OS sandbox and
does not independently intercept every SQL statement.

The launcher uses the existing original-I/O harness bounds: 600 seconds for the
owned test child and 64 MiB raw-state collection. The phase engine retains its
own 60-second cooperative trial boundary, 16 MiB record ceiling, 4096 records and
2048 ticks. No effect, protocol or provider bound is widened. Original private
scratch is never deleted; it is copied after confirmed child termination and
identity-checked before/after. Passing additionally requires exact workspaces,
closed engine manifests, every record hash and all 38 database connection/file
associations. Failed partial states remain retained even when those checks fail.

No full qualification matrix, independent outcome reducer, promotion, public
service, model inference, physical port or target binary is executed. No live
HMS source or adjacent Harness checkout is modified. Primary-agent source review
releases this exact original-host scope; independent review remains unavailable.
