# Independent static policy and single-trial outcome

This candidate reconstructs the complete static I/O contract independently of
the compiler, policy planner and runtime. It proves the whole declared timing
domain before applying selection predicates, including sequential admission,
strict start/completion/run limits and the lease consumed during an early wait.
Applicable intervals, sparse enums, nominal parameters, clock policy and every
retained contract field must match the independently derived document exactly.

A second API joins that check with the complete configuration, correspondence,
permission/recovery, board, operation, parent and sampling history. It evaluates
the declared simulation capability-completion contract as satisfied, failed or
incomplete. Cancellation and a valid permission refusal do not fulfill that
completion objective. An idle board with an unstarted parent remains incomplete.
A rejected child may already establish failure while its parent still reports
running; the checker preserves the actual parent state.

Completed trials require every exact child settled, all required cycles complete,
no unrelated activation, no pending owner or claim, and matching current receipts.
The checker separately compares concrete admission/start/board-completion/authority
times with the zero-lag virtual schedule and checks the parent's completion time.
Historical completion remains distinguishable from compliance with the nominal
schedule. This is simulated capability evidence, not electrical measurement or a
physical task outcome.

The 24-method selection covers all 26 configured fixtures, concrete GPIO/PWM and
sixteen-step outcomes, correct denial/recovery distinctions, purity, exact static
contract attacks, sparse applicability and whole-domain timing boundaries. One
rehash attack demonstrates that the previous complete history checker accepts a
fabricated schedule that this component rejects. All 7,060 inherited project/data
files are unchanged; only one independent module and one test file are added.

The public result does not grant qualification or promotion. Required combined
matrix coverage, wider timing/fault/shared-resource challenges, current-source
attestation, aggregate storage, supervision and public mounting remain required.
Fault trials can correctly fail the completion objective; a future closed matrix
policy must check their expected fault response separately. The static API makes
no execution claim. Complete history validation precedes any outcome decision.
Failed/incomplete outcomes are retained, never reset or retried under new keys.

Original evidence/scratch/deadline bounds remain unchanged. Execution is restricted
to pure tests over already acquired data; no Runtime, SQL connection, physical
device, MCU/emulator, inference, public service or acquired controller runs.
Primary-agent source review only; independent helpers remain usage-limited.
Actual test results are retained separately. No live HMS or adjacent Harness
source is changed by this candidate.
