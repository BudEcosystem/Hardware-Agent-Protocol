# Retained-state audit

After the one candidate attempt terminates, join every process start to its
terminal/reaped receipt; check all frozen sources, compiler/header identities,
native hashes, result receipts and all 244 public baseline inputs. Do not run
the workload again. Check that earlier sealed stages remain byte-exact.

Copy the preceding hierarchy's independent reader unchanged. It opens retained
backing files read-only, checks original object anchors and metadata, and forbids
program, erase and sync callbacks. It mounts only the littlefs reader, never the
hierarchical adapter or its recovery path. Reconstruct each of the 18 semantic
images, both comparison images, and any full-workload image. Compare complete
logical bodies, namespace, interruption/recovery lineage and recorded backing
hashes. Join full-workload progress to the exact original dataset prefix and
inspect any extra published file without repairing it. The additional raw block
fixtures and partial creation are preserved and included in the final byte seal;
they are not formatted or interpreted as a filesystem.

The audit child retains 60 wall seconds, 40 CPU seconds, 512 MiB address space,
128 descriptors and 16 MiB per file. A failure is retained, not silently retried.
No SQLite open, recovery, data mutation, actual mount change or public adoption.
