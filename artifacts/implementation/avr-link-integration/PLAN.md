# AVR serial and foreground integration candidate

This is isolated original-source implementation work. Public source files are unchanged. No candidate has been compiled or executed when this plan was prepared. Parent source review must precede `run_checks.py`; it builds and runs native original-source register models, and separately cross-links an AVR image that must never execute here. No physical port, flashing, emulator, service configuration, acquired Arduino implementation, or hardware is used.

The useful prerequisite to persistent prompt-defined applications is a real composition of the existing finite endpoint with clock, durable boot reservation, UART RX and UART TX. A standing application still needs a renewable deployment lifecycle, local input sequence/freshness model, triggers, bounded feedback, ownership arbitration and explicit hub-loss behavior. Replaying finite OPs does not implement that contract. This candidate does not add or claim a persistent application.

The target remains ATmega328P, declared 16 MHz, 2,048 bytes SRAM, 32,768 physical flash bytes, 32,256 UNO application bytes and 1,024 EEPROM bytes. Synthetic primitive state remains a full 256-byte allowance, and a separate 64-byte protection-service reservation remains. Real RX, clock, EEPROM, boot and TX state replace placeholder driver arrays. No larger target or reduced protection/primitive allowances may be used to obtain a passing receipt.

1. Preserve finite endpoint and framing sources. Factor link pre-feed bookkeeping and validated READY dispatch into internal entry points; retain the original feed API as the same ordered wrapper. Add a pre-feed hook to the existing UART continuity gate while retaining the original API wrapper.
2. Add a fixed 8N1 USART0 owner. Consume one existing `link_next` byte only after UDRE, then write UDR and clear TXC atomically in that order. Report hardware drain separately from empty software frame state. Do not add a second TX ring or a blocking flush.
3. Join the installed primitive callbacks to actual boot/EEPROM and Timer1 state, exact-once clean READY admission, empty-RX deadlines, one nonblocking TX attempt, and endpoint loss servicing. The installation explicitly supplies its receive assembly budget. Every qualified snapshot checks USART ownership after startup. Fault flags latch during callbacks; parser cleanup waits until handling returns.
4. Review and run original native endpoint tests plus the new differential/reference-link and integrated register-model probes under normal and ASan/UBSan builds. Required cases include clean READY, loss before/during/following READY, fresh-clock failure, idle expiry, hardware error/ring loss, TX backpressure with continued endpoint loss service, boot one-shot rules, missing assurance, configuration drift during guard, full wire BIND/ARM/OP/QUERY, and all SREG snapshots around TX ordering.
5. Cross-link the combined foreground and actual RX/Timer1 ISR image using archive-verified AVR GCC 7.3.0. Retain the legacy link/RX wrappers and TX drain API in the ELF as well. Inspect generated UDR/TXC ordering and bounded critical instruction window; analyze the combined call graph, indirect callback edges and non-nested ISR stack. Keep any resource failure as a failure.

Source-review invocation, after parent review:

```
python3 artifacts/implementation/avr-link-integration/run_checks.py native
python3 artifacts/implementation/avr-link-integration/run_checks.py avr
```

`run_checks.py` gives each child process 30 CPU seconds, 60 wall seconds per command, 64 MiB per output file, 64 open files, no core dump, and a sampled 512 MiB process-group RSS limit. Normal children have 512 MiB virtual address space; ASan executions and the unchanged original native suite runner require unrestricted virtual shadow space while retaining CPU/wall/RSS/file bounds. The 20 ms RSS sampling is an observed bound with possible interval overshoot, not a kernel-enforced RSS cap. Root may impose an additional outer bound. It records commands, output files, pins, exact source hashes and failures. It never executes the AVR ELF.

Native and AVR attempts have separate `build/native` and `build/avr` directories, with their own verified source byte copies under each attempt. This also preserves the unchanged original native runner's generated outputs across retries. An existing stage receipt or build directory is refused before execution; an explicit `--attempt 2` (or another fresh positive number) records a new attempt without overwriting any prior failure. Child processes receive a minimal PATH/locale/sanitizer environment. Each command records PID/PGID and direct-child reaping, terminates any owned-group leftovers after completion or failure, and audits group absence. Both original and copied source hashes are checked in the final receipt even on failure. Private source byte copies are not claimed filesystem-immutable.

The initial runner intentionally reports combined stack and TX instruction review as pending; a compile or static-size arithmetic pass alone cannot claim runtime fit. The old endpoint-only 231-byte foreground bound excludes these drivers/ISRs and is inapplicable. Its 512-byte stack reservation, 64-byte ISR planning allowance and 128-byte future callback growth allowance must be reconciled with the actual new linked graph before a capacity conclusion.
