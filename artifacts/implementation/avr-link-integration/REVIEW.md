# Source review and claim limits

Prepared source only: no candidate build/test/target execution has occurred at this point. `source-inputs.json` records the original copied source hashes. `source-reading.json` and the retained extracts identify the selected USART manual/source coverage. No claim of complete manual reading is made.

The current public endpoint has one volatile finite operation/receipt slot. ARM renews context eligibility but cannot extend admitted operation deadlines/lease. Finite PAT accepts neither a standing deployment nor dynamic observations/triggers. The intended persistent application remains the scope in `docs/prompt-to-pat.md`, including explicit offline behavior and local guard/ownership enforcement. This implementation removes a transport integration gap; it does not satisfy that broader contract.

Changed copied production files:

- `project/protocol/endpoint/link.c,h`: unchanged original feed order is factored into deadline/bookkeeping, exactly one parser feed, then validated-frame dispatch. The internal dispatch entry point trusts its serialized adapter to supply actual validated READY exactly once. It is not a new untrusted-frame validator.
- `project/protocol/platform/avr_uart.c,h`: optional bounded nonreentrant pre-feed hook runs after extracting a byte and restoring the saved SREG, before the single feed and the existing final masked loss check. The existing wrapper uses no hook. A loss after the final clean check affects subsequent bytes without retroactively withdrawing the already-linearized READY.
- `project/protocol/platform/avr_usart.c,h`: original fixed 8N1 USART0 owner. The divider is explicit 0..4095, U2X is 0/1, with declared 16 MHz only. Theoretical configured baud ranges from about 244 to 2,000,000; this is not a qualified electrical or scheduler rate. RXB8 is masked because it is received data, not configuration. All writable UCSR0B ownership bits remain checked. UDR precedes TXC W1C with saved SREG, preserving only installed U2X and writing zeros to status/error bits. No extra TX buffer exists. Software-empty, UART-drained, peer acknowledgment and effect completion remain different states.
- `project/protocol/platform/avr_runtime.c,h`: real composition with immutable installation callbacks, explicit receive budget 1..0x7fffffff ms, boot reservation before Timer1 startup, and non-nesting ISR forwarding. UART configuration is checked at each platform snapshot after startup, including the endpoint's post-guard/pre-effect snapshot. Faults latch immediately; parser/continuity reset is deferred to stable post-handle/post-poll points. A fresh post-handle snapshot supplies current flags to poll. A loop services at most one RX byte, one endpoint step callback and one TX byte.

Startup requires a fresh inhibited hardware boot domain, zero-initialized runtime state, global interrupts disabled, exclusive USART0/Timer1/EEPROM ownership and a pre-provisioned finite EEPROM bank. It never formats that bank or erases memory. Startup is one-shot including failures; a later call cannot reserve a second cell. Successful byte write/readback is not storage qualification. Clock assurance bits and simulator/physical mode flags remain explicit installation assertions, with none manufactured by the composition.

The target harness uses actual register adapters and USART RX/Timer1 overflow vectors, but still installs a synthetic primitive and zero boot/clock assurance. It remains inhibited and is never executed. The 64-byte protection reserve is storage accounting, not a physical independent stop implementation. No hardware callback, electrical pin mapping, sensor, actuator, interrupt service bound, power-failure behavior or physical outcome is commissioned.

RX continuity errors reset parser assembly, not endpoint identities, fences, claims or operation state. A failed clock closes RX admission because the assembly deadline lacks a qualified time source, while endpoint loss/quiescence servicing continues. An independent physical stop and independently timed degraded serial service remain unimplemented installation requirements. In particular this candidate does not claim that QUERY/CANCEL over UART continue after clock failure. A USART fault latches RECONCILE and closes that transport. Trusted callbacks must still enforce their provided limits at actual I/O boundaries; polling cannot prevent arbitrary mutation inside a malicious/native driver.

The ring has no acquisition timestamps. The receive budget bounds foreground assembly since first serviced byte, not absolute on-wire age or time spent waiting in a queue. Queue service latency, interrupt blackout, RX overrun and Timer1's strict overflow service interval require board-specific evidence. New APIs do not remove that limitation.
