# AVR finite-endpoint integration candidate

This isolated candidate joins the existing finite endpoint to actual AVR clock, finite EEPROM boot reservation, UART RX, nonblocking UART TX, foreground service and ISR forwarding. The full modeled RX → endpoint → TX path passes native checks, and the combined image links for the unchanged ATmega328P target within the retained arithmetic reservations. Public production files are unchanged. No AVR image, emulator, port, board or physical I/O was executed.

The candidate preserves the finite operation APIs and wire profile. It factors link bookkeeping from validated-frame dispatch so the existing RX continuity gate can deliver clean READY exactly once. Empty-RX deadlines and endpoint loss servicing continue despite TX backpressure. USART ownership is checked in each qualified snapshot, including after guards, with parser cleanup deferred until handling returns. The installation supplies an explicit receive budget. TX consumes the existing response stream only when UDRE permits; software-empty and TXC hardware-drained remain separate.
