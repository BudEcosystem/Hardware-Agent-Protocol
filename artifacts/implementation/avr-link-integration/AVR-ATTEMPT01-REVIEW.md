The original restoration method is recorded in `research/constrained/avr/notes/target-build-and-uart-review.md`: Python `tarfile` with `filter='data'`, a private temporary directory, no global install or PATH change. The already acquired 37,630,618-byte official archive remains pinned by SHA-256 `bd8c37f6952a2130ac9ee32c53f6a660feb79bee8353c8e289eb60fdcefed91e`. A data-only metadata read found 2,097 members, total declared payload 220,276,601 bytes, largest member 15,913,192 bytes, 2,001 regular files, 75 directories, 8 symlinks and 13 hard links.

`restore_toolchain.py` is prepared for parent source review only. It verifies the pinned archive, rejects unsafe/duplicate paths, non-directory ancestors, unsupported member types, excessive extent/count, unresolved link targets or link cycles; extracts with the standard data filter into a fresh mode-0700 private directory; checks the complete member set and each restored file hash against archive bytes; and writes a unique receipt inside that directory. Limits are 60 CPU seconds, 90 wall seconds, 512 MiB address space, 32 MiB per file, 256 MiB declared payload, 3,000 members and 64 open files. Existing failed attempts are preserved.

After source review, the parent can invoke the restoration script and use its emitted `toolchain_bin` with `run_checks.py avr --attempt 2 --toolchain-bin PATH`. The restoration executes no acquired code, compiler, AVR image, installer, device or emulator. The later reviewed runner separately pins compiler tools/headers/libraries before cross-compilation. No source or runner change is needed.
