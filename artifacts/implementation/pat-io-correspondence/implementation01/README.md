# Independent finite PAT-to-instruction correspondence

This isolated candidate preserves all 2,806 inherited project/data files and adds
a pure correspondence checker with 37 tests. The focused selection adds the four
existing methods that inspect all retained histories, totaling 41 tests. The full
historical 146-method selection is not rerun or represented as a current result.
Preparation uses static parsing/hashing only, with no project imports or tests.

The checker independently reads the finite integer PAT profile, parameter domains,
fixed units, GPIO/PWM argument schemas/envelopes, literals, expressions, selection
predicates, timing offsets and effect constraints. It derives exact ordered child
requests from tagged parameter values and the first worker session. A complete
internally consistent execution attributed to different requested values, literals,
step IDs, step counts or timings must refuse. Boolean and integral-number tags
cannot silently become integer values. Context keys and parameter refusals are
checked independently, including the worker's explicit deployment override.

Plan request/PAT/run-binding hashes, dependency metadata, fixed report fields and
original/worker environment records are recomputed and compared. Reopened worker
environments must carry their new session; the compiled request keeps its original
session. Negative lowerings must preserve empty admission/claim/receipt histories,
zero modeled counters and idle resources. The original nineteen trials should
account for eighteen successful lowerings and 35 emitted child requests, plus one
integral-number refusal. These differ from actual admitted-operation counts.

No compiler, PAT policy/parser, registry, Journal, runtime or worker is imported.
Only shared canonical/invocation contracts and independent transcript/typed-model
helpers are used. Adversaries rebuild all outer references/hashes; changed trusted
PAT examples also rehash every associated PAT identity. They must pass structural,
operation and parent inspection before the new correspondence refusal.

Compiler identity is an opaque historical label consistently joined across the
transcript. A fully consistent relabeling does not establish current implementation
attestation; an explicit test preserves that distinction. Separately trusted setup
is still required. The static contract's artifact/descriptor/declaration association
is checked, but its scheduling recurrence and whole-trial timing policy are not
reproved here. Full raw configuration/authorization attestation, required fault and
auxiliary-actor composition, aggregate limits, qualification and live integration
remain unfinished. Board/operation/parent semantics are separate checks. All full
outcome and qualification flags remain false.

No earlier frozen artifact, live runtime or adjacent Harness checkout changes.
No real hardware, MCU, emulator, live inference or external service is run.
Primary-agent review is recorded; helper account limits prevent independent review.
