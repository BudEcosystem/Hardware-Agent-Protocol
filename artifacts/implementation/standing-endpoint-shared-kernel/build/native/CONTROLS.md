# Unexecuted native controls

`standing_controls.c` is byte-identical to the parent: all14 case bodies, invocation order and14/766 observed baseline remain unchanged. Original finite26/2548/20,000+pipe and runtime11/143471/20,000/256 controls are also unchanged. The kernel source is added to every relevant candidate link path, including the original checker; baseline differential binaries use exact frozen original cores.

`kernel_controls.c` has three groups. Its independent reference expressions and literal checks cover every byte carry/borrow boundary, both high-bit halves, MAX-1/MAX, modulo underflow and bounds0/1/60000/UINT32_MAX. For each bound it explicitly tests M-delta-1/equal/+1 where representable, elapsed bound-1/equal/+1 at a high-bit base and equivalent modulo-borrow deltas. It tests prior-min cutoff preservation, native/encoded sums and age encoding. Overlap controls capture native/encoded values before destination writes; sequential context/tail controls deliberately overwrite a later scalar before that scalar's later read. Context memcpy ranges do not overlap. Observation commit checks every field byte and quality/pending flags. These controls are never compiled into the AVR target.

`endpoint_equivalence.c` is one new harness compiled twice per mode. `HMS_EQ_BASELINE` selects exact frozen baseline headers,14 unchanged controls and original cores; the other build selects the candidate. It intercepts API and callback calls while leaving all original case bodies exact. It emits raw replies, endpoint object bytes with only config/standing pointer representations zeroed,128 canonical standing bytes, all256 arena bytes, actual callback argument/configuration bytes, returned primitive metadata, clock snapshots, driver limits/reports and pre/post-effect state. It does not normalize counters, timestamps, flags, evidence or logical values. The entire output must match baseline/candidate and plain/sanitized modes. This is a fixed-corpus comparison, not universal equivalence or full serialization of the link/config objects.

The added finite callback group uses a high-bit clock and tests post-sample latest-start before/equal/after, describe-time advancement seen only at the original later clock callback, guard rejection preceding clock sampling, and malformed timing preceding guard. It checks queued/started/terminal timestamps, response/null-output handling, no dispatch during admission, unchanged ownership/fences on rejection, and successful v1 HELLO plus both explicit v2 DESCRIBE pages with independent identity/layout/timestamp checks.

The public lease group covers seven ARM scenarios: before/equal/after now, exact60000 horizon, horizon+1, ABSENT and context-error precedence. Ten finite admission scenarios cover completion/lease and armed-until equal/adjacent cases, already-expired and ABSENT leases, an earlier expired latest-start, expiry crossed during describe/guard/sample, ARM expiry's earlier BAD_STATE, and bad-context-before-metadata precedence. It never mutates executor storage in a callback to manufacture an unreachable later error: crossing a valid operation lease also crosses latest-start first, and the original earlier status is asserted.
