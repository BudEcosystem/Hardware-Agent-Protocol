# Source change and equivalence review

The private `endpoint_kernel.c/h` contains no static data or callbacks. Decoders retain the original shifts/byte order. Scalar encoders retain the reverse byte-store sequence; write16 retains high byte then low byte. Snapshot/sum encoders read their source completely before the first store. The38-byte context identity and21-byte finite tail share only the existing field sequence; they do not snapshot a whole native structure. Accepted observation commit keeps four copies and quality/continuity/pending/reserved stores before the channel-specific flag.

Time comparisons return a signed three-way result from exact unsigned64 values. Elapsed comparisons retain modulo2^64 subtraction, including end<start. Callers preserve `<` versus `<=`, ABSENT checks, preceding order checks and original short-circuit/error precedence. Saturating cutoff minima retain `at<MAX-delta ? at+delta : MAX`, called in observation0/1/on-time order. Remaining capacity passed as uint32 in `account_ok` is exactly `UINT32_MAX-total`: at that point total is the initial decoded uint32, so the cast does not narrow any possible value. The later account store still precedes its max-on return test.

Finite admission retains `call`, `run`, `nb`, `latest`, `complete`, `lease` locals at their original pre-describe capture point. Post-guard fresh-clock checks use those same timestamp snapshots. Standing ordinary dispatch retains `before`/`cutoff`, activation identity before driver entry, fresh clock/synchronization/source binding after callback and actual dispatch accounting afterward. `dispatch_report` keeps its original ABI; comparison inversions preserve before<=tick<=after and tick<cutoff. Loss service still computes modulo duration before its order/counter refusal, writes its partial witness before that check, and publishes valid/quiescent state only afterward. Interrupted feedback, unknown handoff, ACK/resume/retire gates and common finite/standing claims are unchanged.

Explicit GCC noinline boundaries cover the shared leaves, finite admission/response writers/finite handler and standing OPEN/mutation/DESCRIBE/feedback/evaluate/loss service. The public finite handler preserves initial length clearing and v2 routing before entering the finite-only function. The existing finite poll boundary remains. No blanket compiler flag or byte-loop alternative was added. Other compilers remain source-compatible, without an inferred stack/size qualification. Actual sharing, compiler clones, prologues, outgoing arguments and aggregate stack must be inspected after code generation.
