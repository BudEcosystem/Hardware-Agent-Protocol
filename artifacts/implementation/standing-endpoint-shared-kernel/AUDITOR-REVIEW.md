This new script has not been executed or imported. It does not import candidate files, spawn any process, query a compiler, load the owner helper or signal a process. After a successful future invocation it writes a new `AUDIT.json` with exclusive creation; it leaves receipts, build outputs, sources and parents unchanged.

Invocation requires the independently supplied native and AVR receipt SHA256 values as its two positional arguments. It accepts exactly attempt1 native and attempt1 AVR, verifies their hashes before data joins, and checks each command list against the exact current stage order:26 native commands;13 AVR compilation units including `kernel`,24 commands through link and28 if all linked inspections complete. A stopped prefix remains a failed stage and its observed failure is reported. The script does not predict an AVR flash result or require a particular overflow.
