vertical path uses the copied actual standing C endpoint and its original native
fixture. No public input or sealed parent packet is changed. It does not expose
a physical/public mount or claim protected control-storage capacity.

profile and cumulative limits. It supplies no program, driver path, raw endpoint
packet or qualification result. A separate literal standing PAT compiler/catalog

standing claims authority. The same claims/fence table protects both instance

versions, durable disputes and committed loss episodes govern ACK and retirement.
