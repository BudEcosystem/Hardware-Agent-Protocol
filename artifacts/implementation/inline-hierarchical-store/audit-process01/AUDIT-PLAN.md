# Independent retained-state audit

Use the prior statx candidate's independent reader and bounded runner. The runner
is byte-identical. The reader has three explicit adaptations: an expected
hierarchy profile parameter, an optional native library path, and comparison
against the selected profile. All ownership, descriptor, complete-body,
namespace, physical-inode and forbidden-mutation checks remain intact. Import
the reader as a library; its historical standalone main is not executed.

Join every executed child's start and terminal receipt, require reaping and
absence of its PID, and check the frozen inputs, compiler, headers, old and new
native libraries and original 244 public inputs. Require completed focused and
paired scopes before reporting their claims. The native probe has 12 cases;
mount, original provider, profile and hierarchy scopes contain 52, 24, 8 and 96
checks respectively. Internal native assertions are reported separately.

Reconstruct all 18 retained semantic images through strictly read-only held
backing descriptors. Preserve the original recovery lineage, missing-chunk,
duplicate-graph, orphan, replacement-owner and failed-write checks. Independently
inspect both profile fixtures. The refused fixture deliberately contains an old
superblock profile and a retained super.tmp file, so select the old expected
profile with the new native library solely for read-only evidence inspection.
This is not adapter admission, migration or recovery.

Inspect both comparison images with their respective explicit hierarchy
profiles and pinned binaries. Verify all 40 complete payloads, 20 directories,
inode metadata, links and 426 logical operations. Timings and native callback
counts may differ. The statx provider manifest and full fsync of all eight chunks
remain identical in policy. Physical filesystem encodings must differ across
variants while each individual image remains byte-exact through inspection.

If the full writer ran, join the complete progress prefix to the exact original
dataset and reconstruct every published body and directory. Record any partial
progress tail, next published file, pending entry, unlinked inode or incomplete
physical inode. A completed writer must contain all 4,270 files and all 169
directories. An interrupted writer is never reopened by the adapter, repaired
or passed to SQLite. The dependent cold-reader result is reported only if run.

Independently open both 2 MiB RAM-model snapshots O_RDONLY|O_NOFOLLOW, hold their
identities and exclusive nonblocking flocks, and verify the empty boundary file,
299 remaining 32-byte files, rename/removal results, allocated-block traversal
and equal snapshot hashes. All mutation callbacks raise. Recheck held/named
identity and full hashes after native unmount. These snapshots model callback
durability; they do not constitute physical power-loss testing.

Freeze audit sources before a single child run with 60 wall/40 CPU seconds,
512 MiB address space, 128 descriptors and 16 MiB per-file limits. Save actual
stdout/stderr and process receipts. The audit creates reports only; it does not
repair or change any image or public runtime input. No upstream test harness,
device, mount or administrator action is run.
