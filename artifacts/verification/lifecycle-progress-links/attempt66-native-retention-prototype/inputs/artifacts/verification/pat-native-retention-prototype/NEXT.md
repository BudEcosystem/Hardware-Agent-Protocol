# Next work

The native prototype is a measured candidate, not a deployed optimization.
Preserve the original Python implementation, all failed worker attempts and the
trace parser failure. Do not rerun the unchanged qualification scope, expand its
60/180-second deadlines, reduce the 30-case matrix, weaken traversal checks or
storage/effect limits, or repair interrupted case state.

Define and verify an in-process Linux binding before adoption. A subprocess per
scan is not the intended runtime architecture. The binding needs a fixed ABI,
bounded input conversion, exact artifact/platform identity, explicit descriptor
ownership, error mapping and signal/cancellation behavior. A borrowed directory
descriptor cannot simply be duplicated with an assumed fresh stream offset.
Native calls bypass Python audit hooks; retain equivalent explicit authority and
origin checks at the binding, and verify actual native operation boundaries.

Extend the isolated failure controls before integrating: stream-construction and
stat failures, cleanup failure precedence, descriptor exhaustion and leaks across
repeated failed calls, concurrent entry replacement/disappearance, and differences
between Python and native signal behavior. The five traced fixture scopes cover
three injected failures but do not establish every race or cleanup path. Keep
the Linux close semantics explicit and do not retry a failed close by stale
descriptor number. The C prototype's bounded numeric CLI is not the full Python
input contract; preserve supported call semantics or make profile differences
explicit instead of silently changing them.

Then create a fresh isolated supervisor candidate with independently recomputed
source/producer/consumer identities and unchanged original worker bounds. Run the
complete actual authority-vault import before making any whole-worker performance
claim. The held-snapshot catalog integration and immediately-before-business-commit
validation remain separate requirements, as recorded in the
[catalog review](../../implementation/pat-vault-original-run/CATALOG-NOTES.md).

Public qualification/PAT mounting, backed control capacity, natural-language
synthesis and validated learning, persistent Arduino applications, actual I/O,
driver and intelligence-hub providers, wider research and physical commissioning
remain required. No part of this host metadata optimization completes those
device-control obligations.
