# Authority-vault PAT catalog and deterministic execution

**Verified isolated integration:** 19 catalog controls pass, followed by the
complete original thirty-case simulated worker, real evidence reduction and vault
publication, catalog promotion, one completed GPIO PAT application and original-key
replay after configuration drift and cold vault/bridge reconstruction.

The original worker finishes in approximately **58.35 seconds** within its
60-second bound. The complete parent finishes in **133.99 seconds** within 180.
The original matrix, storage limits, five-second snapshot lifetime and one
application invocation remain unchanged. No physical device, MCU, live inference
or public service executes.

The [design](DESIGN.md) implements a distinct recorded profile. Preparation
validates original evidence outside the admission transaction. Selection gathers
all relevant authorized PATs into one bounded held vault view. Current source
applicability, the complete catalog inventory and held evidence are checked again
immediately before admission commits. Historical request keys retrieve their
original instance without fresh preparation or qualification.

The control audit verifies **1,149 files, 76 databases and 99 original owner/writer
locks**. Four admitted control fixtures each retain one instance and procedure;
every refusal fixture retains neither. Two intentionally missing evidence bodies
remain missing. The controls use an explicitly substituted semantic oracle and
start no qualification worker.

The separate actual audit verifies **4,264 retained files, four source databases
and 57 original owner/writer locks**, without opening any worker case database.
All 4,011 vault references and 2,798 bodies match their original documents and
inspection records. It independently recomputes producer/consumer/host identities
and joins the publication, catalog evaluation, promotion decision, PAT instance,
procedure and completed operation. The actual integration substitutes no oracle.

Earlier failures remain retained: the aggregate control child was killed before
final receipts; two smaller scopes passed their methods but failed the older
native origin auditor; a complete-inventory test failed while emitting tuples
instead of JSON arrays; and the first actual harness stopped at a missing module
search path before launching a worker. Corrections use fresh sources or harnesses.
The final harness index also contained an invalid zero-byte self-entry; its exact
original bytes remain, with a separately verified [input-index correction](harness23-inputs-correction.json).
No execution was repeated to correct that metadata.

This is a single-role finite synthetic-I/O profile. Natural-language synthesis,
learning, persistent Arduino programs, physical device and bus providers, driver
lifecycle, intelligence-hub management, backed control capacity and public runtime
integration remain unfinished. The broader HMS goal remains active.
