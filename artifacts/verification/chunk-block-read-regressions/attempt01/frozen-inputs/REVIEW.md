# Pre-execution review

Primary-agent review only. The candidate and binary are byte-identical to the
sealed stage 86 block-read evaluation. No compiler rebuild, provider change or
semantic oracle adjustment is required. The driver freezes and checks the exact
original files, then invokes the same semantic and interruption entry points.
The bounded process runner is copied exactly from stage 86.

The shared 4 KiB native cache changes how many reads reach the fixed provider and
uses more RAM; passing counts from the earlier 256-byte-cache matrix cannot
qualify it. This gate tests the same selected failure/ownership boundaries on
the new profile. It changes no endpoint, driver, hub or public runtime behavior.

The test inventory is finite and predeclared. Every original interrupted image
is preserved; recovery copies receive distinct host anchors and retain raw byte
lineage. Any failed process remains terminal and prevents later cases. A final
read-only audit must reproduce the data/namespace oracles and inspect original
process records before the stage is sealed. Read-only checks do not invoke
recovery or repair any evidence.
